개인정보처리방침

문서 기준일: 2026-10-10

이 방침은 필름 촬영 보조 앱 ShutterNote의 카메라, 사진, 설정 및 거리 측정 관련 데이터 처리 방식을 설명합니다.

1. 카메라와 센서 사용

카메라는 수동 노출 프리뷰, 사진 촬영, 중앙 피사체 거리 측정에 사용됩니다. 거리계는 Google Play Services for AR(ARCore)을 통해 카메라와 움직임 센서 정보를 사용합니다. 권한을 거부하면 관련 기능을 사용할 수 없으며, 기기 설정에서 카메라 권한을 변경할 수 있습니다.

2. 사진 처리와 저장

앱의 노출 보정은 기기에서 처리되며, 앱 자체는 촬영 사진을 개발자 서버에 업로드하지 않습니다. 저장 버튼을 누르면 결과가 기기의 Camera (DCIM/Camera) 앨범에 저장됩니다. 파일명에는 촬영 설정, 촬영 시각이 포함됩니다.

앱은 촬영 결과 복구를 위해 기기 내 앱 캐시에 임시 사진을 저장합니다. 생성 후 24시간이 지난 파일은 다음 메인 화면 또는 노출계 진입 시 정리됩니다. 사용자가 앱을 다시 열지 않으면 정리 시점이 늦어질 수 있고, 운영체제가 캐시를 먼저 지울 수도 있습니다. 갤러리에 저장한 사진은 이 임시 파일 정리 대상이 아닙니다. 임시 사진 정리 시 원본 파일이 없는 저장 완료 기록도 삭제합니다. 원본이 남아 있는 촬영의 저장 완료 기록은 중복 저장 방지를 위해 유지합니다.

필름 노트의 컷 저장은 사진을 갤러리 대신 앱 내부에 보관합니다. 컷별 사진·메모·촬영 시각·촬영 당시 노출값은 롤과 함께 기기에 보관하며 임시 캐시의 24시간 정리 및 Android 백업·기기 이전에 포함하지 않습니다. 롤을 삭제하면 해당 컷 기록과 사진을 함께 삭제하며 앱 삭제 또는 데이터 초기화 시에도 삭제됩니다.

사용자가 롤 사진 ZIP 내보내기를 실행하면 해당 롤의 촬영 사진만 컷 번호대로 묶어 시스템 파일 저장 화면에서 선택한 위치에 저장합니다. 연결 스캔·메모·좌표 등 롤 기록은 ZIP에 포함하지 않습니다. 원본 사진은 앱 내부에 유지하며 내보내기용 임시 사본은 완료·취소·실패 시 정리합니다. 내보낸 ZIP은 앱 삭제로 지워지지 않으며 사용자가 직접 관리하고 PC로 옮길 수 있습니다. 저장 대상으로 클라우드 제공자를 선택하면 해당 제공자의 정책에 따라 파일이 저장될 수 있으며 앱이 개발자 서버에 업로드하지 않습니다.

필름 노트에서 실제 필름 스캔본을 비교용으로 연결할 수 있습니다. 시스템 사진 선택 화면에서 사용자가 선택한 사진 한 장만 읽고 원본 파일을 앱 내부에 복사합니다. 앱은 갤러리 전체 읽기 권한을 추가로 요청하지 않으며 선택한 갤러리 원본을 수정하거나 삭제하지 않습니다. 연결된 스캔본은 개발자 서버로 업로드하지 않고 컷과 함께 기기에 보관하며 Android 백업·기기 이전에서 제외합니다. 연결 해제·교체 또는 컷·롤 삭제 시 해당 내부 사본을 삭제하고, 앱 삭제·데이터 초기화 시에도 삭제합니다. 연결 확인용 임시 사본은 선택 취소·화면 종료 또는 생성 후 24시간이 지난 뒤 비교 화면 진입 시 정리합니다.

새 필름 롤을 만들 때 위치 권한을 요청합니다. 허용하면 사진 촬영이 끝난 뒤 앱을 사용하는 동안 최대 10초간 기기 위치와 제공되는 정확도를 가져옵니다. 앱 안에서 다른 화면으로 이동하거나 다음 사진을 찍어도 해당 사진의 조회는 이어지며, 위치를 받거나 제한 시간이 끝나거나 앱이 백그라운드로 가면 즉시 중지합니다. 위치 조회는 셔터 촬영·결과 표시·사진 저장을 지연시키지 않습니다. 사진이 먼저 저장되면 도착한 위치를 해당 컷에 자동 추가합니다. 대략 위치 권한도 사용할 수 있습니다. 거부하거나 위치를 구하지 못해도 사진과 메모는 유지하며 촬영할 때마다 위치 권한을 요청하지 않습니다. 저장하지 않은 결과를 취소하면 조회를 중지하며 백그라운드에서는 수집하지 않습니다. 사용자가 지도에서 선택하거나 좌표를 입력해 위치를 추가·수정할 수 있고, 현재 위치 가져오기 버튼에서도 권한을 요청할 수 있습니다. 저장한 좌표와 정확도는 해당 컷과 함께 기기에 보관하며 개발자 서버로 전송하거나 Android 백업·기기 이전에 포함하지 않습니다. 위치만 삭제하거나 컷·롤 삭제 및 앱 데이터 초기화로 지울 수 있습니다. MapLibre로 OpenStreetMap 지도를 표시하며 지도 조회 시 지도 영역을 나타내는 타일 요청, IP 주소와 앱 식별 정보가 tile.openstreetmap.org에 전달됩니다. 지도 타일은 기기 캐시에 보관할 수 있습니다. 저장된 지도나 좌표를 눌러 Google Maps를 열면 해당 좌표를 Google에 전달하며 Google 개인정보처리방침이 적용됩니다. OpenStreetMap의 방침은 https://osmfoundation.org/wiki/Privacy_Policy 에서 확인할 수 있습니다.

3. 설정과 백업

앱은 노출값, 화각, 언어, ARCore 안내 확인 여부와 중복 저장 방지를 위한 저장 상태를 기기에 보관합니다. Android 백업 및 기기 간 이전에는 노출값·화각·앱 언어 설정을 포함합니다. 실제 백업·복원 여부는 기기와 백업 서비스 설정에 따라 달라질 수 있습니다. ARCore 안내 확인 여부와 촬영 저장 기록은 백업·이전 대상에서 제외하며, 새 기기에서는 ARCore 안내를 다시 표시합니다. 앱 캐시의 임시 사진도 백업하지 않습니다.

앱 자체에는 회원가입, 광고 SDK 또는 별도의 사용자 행동 분석 서비스가 없습니다.

필름 노트에서 입력한 필름·카메라 이름, 롤 이름, 예정 컷 수, 화각, 촬영 기간 및 현상·스캔 메모는 기기 내 앱 데이터에 저장합니다. 개발자 서버로 전송하지 않으며 Android 백업·기기 이전에 포함하지 않습니다. 롤 기록은 촬영 임시 캐시의 24시간 정리 대상이 아니며 앱 삭제 또는 데이터 초기화 시 삭제됩니다.

4. Google Play Services for AR

거리 측정 기능은 Google이 제공하는 ARCore를 사용하며 해당 서비스에는 Google 개인정보처리방침이 적용됩니다. Google의 ARCore 문서는 계정 또는 기기 식별자, 성능·진단 정보, API 사용 및 앱 활동 정보를 분석과 서비스 개선 목적으로 수집·처리한다고 설명합니다. Google에 대한 데이터 전송은 HTTPS로 암호화됩니다.

이 앱은 ARCore Cloud Anchors 및 Geospatial API를 사용하지 않습니다. 거리계 기능을 사용하지 않아도 노출계와 사진 저장 기능을 사용할 수 있습니다. ARCore의 데이터 처리 및 보관에 대한 자세한 사항은 아래 Google 문서를 참고하세요.

5. 삭제와 관리

기기의 앱 설정에서 앱 데이터를 삭제하거나 앱을 제거하면 앱 내부에 보관한 설정과 데이터가 삭제됩니다. 갤러리에 저장한 사진은 갤러리에서 직접 삭제해야 합니다. 기기 또는 사진 백업 서비스에 저장된 사본은 해당 서비스에서 별도로 관리해야 합니다. Google이 처리하는 ARCore 데이터는 Google의 방침과 계정 관리 기능을 따릅니다.

사진을 길게 눌러 확인하면 해당 컷의 사진·메모·촬영 기록을 삭제할 수 있습니다. 다른 컷 번호와 롤 정보는 유지됩니다. 마지막 사용 카메라·기종별 사용 횟수·최근 사용 순서 및 롤별 마지막 ISO는 기기 내에 별도로 저장하며 개발자 서버로 전송하거나 Android 백업·기기 이전에 포함하지 않습니다. 롤 삭제 시 해당 롤의 ISO 기억을 지웁니다. 카메라 사용 이력은 롤 삭제 후에도 유지되며 앱 데이터 초기화 또는 앱 삭제 시 삭제됩니다.

필름 노트 촬영에서 선택한 마지막 화각도 롤별로 기기에 저장합니다. 일반 촬영 보조 화각과 별도로 관리하며 백업·기기 이전에 포함하지 않습니다. 롤을 삭제하면 해당 화각 기억도 삭제됩니다.

자주 사용하는 필름 목록을 위해 필름별 사용 횟수와 최근 사용 순서를 기기에 저장합니다. 새 롤의 기본값으로 마지막 저장한 화각과 예정 컷 수도 기억합니다. 이 정보는 백업·기기 이전에서 제외되며 앱 데이터 초기화 또는 삭제로 지워집니다.

6. 이 웹페이지

이 페이지에는 별도의 광고나 방문 분석 스크립트를 넣지 않습니다. 페이지 제공 과정에서 호스팅 서비스가 IP 주소 등 접속·보안 정보를 처리할 수 있습니다. 외부 링크를 열면 해당 서비스의 개인정보처리방침이 적용됩니다.

7. 변경 안내

기능이나 데이터 처리 방식이 바뀌면 이 방침과 문서 기준일을 갱신합니다. 필요한 경우 앱에서도 변경 내용을 안내합니다.
